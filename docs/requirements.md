# 要件

## プロダクト範囲

初期公開版は OpenAI Signals v3.0 の公開集計を使う日本語ダッシュボードです。実装着手前にデータスナップショットを再確認し、ページ上にリリース版・取得日・対象期間を表示します。

## MVP 機能

### 1. 日本の職務活動

- 国コード `JP` の仕事関連メッセージを対象にする。
- O*NET IWA 165分類を四半期別にランキング表示する。各 IWA の英語原ラベル・IDと日本語表示名を識別できるようにする。
- 1分類の構成比、四半期順位、期間変化を確認できる。
- IWA の利用可能期間は2025年第1四半期〜2026年第3四半期。月次値や2024年までの値を補間・推定して作らない。
- 分母を「その国・四半期の仕事関連メッセージ」と表示する。
- `Other IWA` を独立カテゴリとして残し、他分類へ再配分しない。

### 2. 日本の仕事利用・用途

- 仕事関連メッセージの構成比と非仕事関連との推移を月次表示する。
- 仕事関連メッセージのトピック構成を、Writing、Practical Guidance、Seeking information、Technical help、Multimedia、Self-expression、Other/Unknown の7区分で表示する。
- Ask / Do / Express の構成を追加表示する場合、仕事関連に限定した分類であることを明記する。
- 日本の月次データは2024年7月〜2026年9月の27期間。

### 3. 日本と世界・指定国の比較

- 月次の仕事関連比率・仕事トピックは JP、公式グローバル集計、利用可能な選択国を同じ期間で比較できる。
- 国別データの欠損・非公開期間を示し、欠損をゼロとして描かない。
- IWA は JP と利用可能な指定国を同じ四半期で比較できる。世界 IWA 集計は存在しないため、IWA の世界比較を表示しない。
- 国別人口調整順位を補足する場合、順位は1が高い人口当たりメッセージ順位であり、利用者数・普及率ではないと説明する。

## 第2フェーズ

- 日本の公式職業統計の定義、期間、母集団、職業分類を調べる。
- 日本の職業分類と O*NET IWA / occupation taxonomy を結ぶ対応方法と限界を記録する。
- 比較できる統計単位が確認できた後で、職業構成と Signals の仕事関連メッセージ構成のギャップ分析を設計する。
- 直接対応しないカテゴリは無理に割り当てず、未対応・複数対応を可視化する。

## 表示・説明要件

- サイト名とデータの帰属を示し、非公式・独立のプロジェクトと明記する。
- `share_of_messages` はメッセージ構成比であり、利用者数・利用者比率・国民や就業者の割合ではないと説明する。
- すべてのグラフで時間粒度、指標、分母、対象母集団を確認できる。
- DP による統計ノイズ、少数グループの非表示、丸めによって合計が厳密に100%にならないことを案内する。
- 公式の分類名と日本語訳を区別し、独自の翻訳で分類定義を変えない。
- モバイル幅、キーボード操作、色以外の識別手段を考慮する。

## 技術・運用要件

- SvelteKit、TypeScript、Cloudflare Pages を前提とする（D-013）。
- 原則静的配信とし、公式 CSV から必要な JSON をビルド前処理する。
- MVP では DB、ユーザー登録、サーバー側のユーザーデータ収集を設けない。
- データ更新時は公式ソース、リリース版、取得日、期間、CSV スキーマ変更を確認してから公開する。
- 元 CSV と変換後 JSON の数値が同じ指標・同じ分母を保つよう、再現可能な変換手順を用意する。
