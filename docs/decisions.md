# 決定記録

## D-001: プロジェクト名と位置づけ

- **決定**: Signals Japan Insight。OpenAI Signals を使う非公式・独立のダッシュボードとして扱う。
- **理由**: 日本を主題とする名称を保ちつつ、OpenAI 公式サービスとの誤認を避ける必要がある。
- **結果**: README と将来の画面で非公式表示を明示する。OpenAI のロゴ・商標を提携を示す形で使わない。

## D-002: データの一次ソース

- **決定**: OpenAI Signals v3.0 の公式 CSV ZIP とデータ辞書を一次ソースとして採用する。
- **根拠**: 2026-10-27 JST に OpenAI 公式記事、Signals データページ、ダウンロードページ、CSV ZIP、データ辞書を確認した。
- **結果**: 更新時に版・期間・列を再検証し、同じ画面で複数版を混在させない。

## D-003: MVP の機能

- **決定**: 日本の IWA 165分類ランキング・推移、仕事用途、国際比較を MVP とし、日本の職業統計とのギャップ分析は第2フェーズに置く。
- **根拠**: 公式 CSV は JP の IWA を7四半期、各期165値で公開している。職業統計との対応には別のデータ・分類調査が必要。
- **結果**: 第2フェーズの職業比較を初期画面や未検証の推定値に混ぜない。

## D-004: 世界比較の範囲

- **決定**: global と JP の比較は月次の仕事関連比率・トピック・Ask/Do/Express に適用する。IWA は JP と指定国の比較に限定する。
- **根拠**: `share_of_work_related_messages_by_onet_iwa_country_quarter.csv` は `quarter,country,iwa_cleaned,share_of_messages` を含む国別ファイルのみ。global IWA CSV と絶対件数・加重分母は公開されていない。
- **結果**: 国別シェアの単純平均から「世界 IWA」を作らない。

## D-005: 指標の意味

- **決定**: 公式 `share_of_messages` をメッセージ構成比として表示し、利用者数・就業者数・普及率・絶対件数と表現しない。
- **根拠**: データ辞書は `share_of_messages` を該当グループのメッセージ比率として定義し、人口補正順位も別の `rank` 列で提供している。
- **結果**: すべてのグラフに時間、分母、対象範囲を明記する。

## D-006: 技術構成

- **決定**: SvelteKit、TypeScript、Cloudflare Pages、静的配信を基準とし、CSV から JSON を前処理する。初期段階で DB は置かない。
- **理由**: 公開済みの集計データを読むダッシュボードであり、初期版にユーザー状態や更新 API を必要としない。
- **結果**: データはビルド時に固定し、更新日・リリース版を見せる。将来の要件変更はこの記録を更新する。

## D-007: ライセンスと帰属表示

- **決定**: Signals データを CC BY 4.0 の条件に従って利用・表示し、OpenAI Signals v3.0 と出典 URL を帰属表示する。
- **根拠**: OpenAI の公式ダウンロードページとデータ辞書に明記されている。
- **結果**: データ利用許諾が OpenAI の商標利用や公式承認を意味しないことも明示する。

## D-008: データ前処理の実装方式

- **決定**: 公式 ZIP は `data/source.json` に SHA-256 で固定し、取得物（`data/raw/`）は git 管理外とする。生成 JSON（`data/processed/<release>/`）は git 管理し、サイトのビルドはネットワークに依存しない。前処理は TypeScript で書き、Node.js 22.18 以降の型除去で直接実行する。依存は ZIP 展開用の `fflate` のみとする。
- **理由**: 公式データの更新を自動で取り込まず、版の確認を経てから更新したい。生成物を管理すると、データの変更が差分として見え、Cloudflare Pages のビルドも再現しやすい。
- **結果**: 公式ファイルが変わると `data:fetch` が停止する。版を確認して `source.json` の `release` を更新し、`--accept-new` で取り込む。

## D-009: IWA の表示名

- **決定**: 英語ラベルはデータ辞書の IWA 一覧（332件）から抽出し、原文のまま保持する。日本語表示名は本プロジェクトによる非公式訳として `data/reference/iwa-labels.csv` で管理し、データに現れる IWA にだけ付ける。
- **理由**: 公式の日本語訳はない。英語原文と ID を残せば、訳の正確さを利用者が確かめられる。
- **結果**: 新しい IWA がデータに現れ、日本語表示名がないと `data:build` が停止する。画面では日本語名・英語原文・ID を区別して示す。
